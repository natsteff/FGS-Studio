# Public Example sheets

Only put examples approved for public redistribution in this folder. Every
`.fgs` file here is copied into the static site and can be downloaded directly
after publication; hiding a sheet from the chooser would not make it private.

Use a lowercase hyphenated filename ending in `.fgs`. `npm run build` validates
each FGS document, copies it, and generates `examples/catalog.json` from the
document title and first header subtitle. No catalog editing is required.

Before adding a sheet, review all fields—including Designer Notes, footer,
reference text, logos, names, URLs, and health or safety instructions—for
private information, publication rights, accuracy, and unwanted endorsement.
Test the rendered preview and PDF as well as FGS validation. Keep candidates
under review outside this folder until publication is approved.
